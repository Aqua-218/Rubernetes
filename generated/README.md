# Generated Artifacts

This directory contains reproducible compiler output grouped into `ruby/`, `rbs/`,
`openapi/`, and `fixtures/`. Files below these directories are never edited by hand.
CI regenerates them from `schema/` and fails when the regenerated tree differs from these
source-tree artifacts.
