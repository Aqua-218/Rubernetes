# 0. この文書について

> 対象読者: 全読者、仕様編集者
>
> **Status:** Normative — version 0.2

規範用語、優先順位、未決事項を残さないための文書規則を定義する。


本書は実装、検証および互換性判定の規範仕様を定める。設計図は
`00-overview` 〜 `08-verification` の各図を参照する。図が構造を、
本文が振る舞いと規約を担当し、食い違う場合は本文を正とする。

本文中の **MUST**、**MUST NOT**、**SHOULD**、**MAY** は要件強度を表す。
無印の要件は **MUST** と同じ強度を持つ。未決マーカー、後続版への先送り、
および実装時判断は本書では禁止する。環境依存の値は、既定値、
許容範囲、変更方法および互換性への影響を同時に定義しなければならない。
